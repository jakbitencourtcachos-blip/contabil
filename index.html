Webhook do n8n

URL usada no POST do FormData

Payload enviado ao n8n

  • arquivo → PDF anexado (binário)
  • cliente, documento, numero_processo, orgao, periodo, tipo_analise, email, telefone, observacoes
  • usuario_email, usuario_nome → quem enviou

O fluxo devolve JSON com resumo + arquivo_base64 (ou file_url) do Word.

O nó Webhook do n8n precisa responder com Access-Control-Allow-Origin: * para funcionar no navegador.
